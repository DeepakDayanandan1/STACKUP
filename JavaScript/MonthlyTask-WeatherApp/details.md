TASK: WEATHER APP USING ASYNC JAVASCRIPT
Objective: Create a Weather App using HTML, CSS, and JavaScript to understand asynchronous
JavaScript concepts such as fetch(), async/await, and error handling.
Requirements
1 User Input: Create a search box where users can enter a city name (e.g., Kochi, Trivandrum, or
Bangalore).
2 Fetch Weather Data: Use the JavaScript fetch() API to retrieve weather information from a
weather API.
3 Use Async/Await: Use an async function and await to fetch the weather data and wait for the API
response.
4 Display Weather Information: After successfully fetching the data, display the following details on the
webpage:
• City name or location
• Current temperature in Celsius
• Weather condition (e.g., Sunny, Cloudy, or Rainy)
5 Handle Errors: Display an appropriate error message if the user enters an invalid city name or if the
API request fails.
6 User Interface: Design a simple and user-friendly interface using HTML and CSS.
Expected Output
When the user enters a city name and clicks the Get Weather button, the application should display the
weather information for that location.
Example:
City: Kochi
Temperature: 30°C
Weather Condition: Cloudy
Note: The values above are only examples. Display the actual weather information returned by the API.
Concepts to Practice
• JavaScript Promises
• fetch() API
• async/await
• JSON data handling
• Error handling using try...catch
• DOM manipulation
• Event handling
Instructions
• Choose a weather API, such as OpenWeather API.
• Obtain an API key if required by the selected API.
• Do not hardcode weather information; fetch the data dynamically from the API.

• Test the application with valid and invalid city names.
Deliverable: Submit the complete project containing HTML, CSS, and JavaScript files.
